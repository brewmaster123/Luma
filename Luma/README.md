# Luma 0.4.1 — исправление Apple Watch

Исправлены состояния кнопок и разрешений Watch, добавлены видимая проба и пауза/возобновление. Общий bundle ID — com.sevchlenko.luma, версия 0.4.1 (5). [Изменения](Docs/CHANGES-v0.4.1.md), [разбор видео](Docs/WATCH-VIDEO-FIX.md).

Все звуковые будильники, REM-подсказки и проба iPhone переведены на AlarmKit (iOS 26+), включая мелодии, записанный голос и импортированные звуки.

**Обязательная автоматическая остановка при приостановленном или принудительно закрытом приложении пока не обеспечена.** Luma вызывает stop по сохранённому сроку, пока её код выполняется. Короткая дорожка может повторяться, если stop не выполнится. Это тестовый пакет. Подробности: [TECHNICAL-NOTES](Docs/TECHNICAL-NOTES.md).

Убраны панель «Будильник в беззвучном режиме» и выбор типа доставки. Старые телефонные будильники переводятся автоматически. Справка REM содержит текст пользователя с минимальными исправлениями и девятью абзацами. Сохранены сортировка по следующему срабатыванию, широкая область редактирования времени, локальный голосовой дневник и интерфейс с Manrope.

Переключатель вибрации iPhone удалён: вибрацией AlarmKit и отражением на Apple Watch управляет система. Дополнительная Watch-серия при телефонном сигнале не отправляется. Watch-only сохраняет конечные уведомления с интервалами 3/8/12 секунд.

## Сборка

Цели проекта: Luma и Luma Watch. Workflow использует Xcode 26.3. Bundle ID и подпись — Config/Base.xcconfig. [Инструкция](../Luma-START.md).

Ядро: swift test. Структура: python scripts/check-static.py. Проверка на macOS: bash scripts/check-on-mac.sh. Фактически выполненные проверки: [VALIDATION](Docs/VALIDATION.md). Xcode и испытания на iPhone/Watch здесь не запускались.

Дневные пробы: [DEVICE-TESTS](Docs/DEVICE-TESTS.md). HTML в Design — интерактивный макет, не работающий AlarmKit и не iOS Simulator. Точность REM в Luma не измерена.

Основа — Luma 0.4; исправление watchOS из подтверждённой рабочей сборки сохранено. Не удаляйте установленное приложение ради обновления: удаление стирает локальную историю и аудио.
