# Luma 0.5.0 (8)

В режиме «iPhone + Watch» телефон теперь воспроизводит конечную мелодию своим плеером, а часы получают отдельную серию. Это позволяет проверять звук обоих устройств без зависимости телефонного плеера от перенаправления уведомлений Apple. Сохранены собственный голос, импорт мелодий, локальный дневник и автоматическое окончание звука.

Для заблокированного iPhone нужен явно запущенный ночной сеанс с настоящим анализом звука: «Часы + микрофон» → «Начать ночь». Само добавление будильника не включает микрофон. При недоступности плеера остаётся обычное резервное уведомление будильника через пять секунд; система может направить его только на часы. Новые REM-сигналы часов требуют доступной связи с работающим приложением Watch. Непрерывность этой связи и ночных датчиков пока не подтверждена.

## Запуск

[Инструкция установки](../Luma-START.md) в корне архива. Замените папку Luma целиком, запустите включённый GitHub workflow до поездки к Mac. Затем установите обе части поверх прежней копии с той же Team и идентификатором com.sevchlenko.luma. Версия на обоих устройствах — 0.5.0 (8). Минимумы iOS 17 / watchOS 10; Xcode 26+ включает отмену старых AlarmKit-записей.

## Проверено здесь

59 XCTest ядра без ошибок, 92 структурные проверки, синтаксис всех Swift Sources и браузерный макет. Это не сборка с Apple SDK и не проверка на iPhone/Watch. [Результаты](Docs/VALIDATION.md), [дневная проверка на двух устройствах](Docs/DEVICE-TESTS.md), [схема совместной доставки](Docs/NOTIFICATION-ROUTING.md).

AlarmKit не планирует новые сигналы. «Только iPhone» использует обычные конечные уведомления, «Только Watch» — прежнюю независимую серию. Алгоритм REM и его точность не изменены этим обновлением.
