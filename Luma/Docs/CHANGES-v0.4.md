# Изменения Luma 0.4 — 12 сентября 2026

Основа: Luma-iPhone-AppleWatch-v0.3.zip, SHA-256 37d5a29c0891f2661abfea2d8601582ee2dcc77a6b3e3b190aa3e5c5c2820c34.

- Обычные будильники, REM и проба iPhone используют AlarmKit; на iOS ниже 26 звуковой режим возвращает ошибку.
- Голос и файлы передаются как именованный звук. Срок stop определяется реальной длительностью аудио.
- Добавлены сохраняемые сроки stop, восстановление просроченных сигналов, отмена после завершения сеанса и повтор cancel после системной ошибки.
- Убраны выбор shortCue/systemAlarm и панель Silent Mode; старые телефонные будильники переводятся при запуске.
- Убран неработающий для AlarmKit тумблер вибрации iPhone. Дополнительные Watch-сигналы не дублируют системное отражение.
- Справка REM: текст пользователя, исправления орфографии/пунктуации, девять абзацев.
- Сохранены голосовые заметки и отклики, импорт звуков, сортировка, широкая область нажатия времени, интервалы Watch 3/8/12.
- Версия проекта 0.4.0 (4); новое ядро AlarmStopWindow включено в обе цели.

**Нерешённое требование:** гарантированная автоматическая остановка при приостановке/закрытии Luma. stop зависит от выполнения кода. Короткий файл не гарантирует прекращение системного звонка. Пакет предназначен для проверки.

Результаты: VALIDATION.md. Испытания устройств: DEVICE-TESTS.md. Проценты из авторской справки не являются измеренными характеристиками Luma.
