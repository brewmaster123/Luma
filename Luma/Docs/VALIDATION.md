JavaScript проверен `node --check`; браузерные проверки завершились без pageerror. Использован подставной тестовый микрофон Chromium, а не голос пользователя. Подробности: `audio-preview-checks.json`. Браузерный импорт использует Web Audio; он не является тестом нативного AVAudioConverter.

Для macOS добавлен `scripts/check-audio-on-mac.sh`, который компилирует фактический CueAudioImporter.swift и проверяет 2/40 секунд stereo 48 кГц → mono PCM 22.05 кГц ≤28 секунд, плюс отклонение неаудиофайла. Этот тест ещё должен выполниться на GitHub.

Исправление watchOS NotificationService сохранено без изменения: SHA-256 `a6897bffa2b13423ae815293cde01f808fce634db24b90a6fddffb80d0666215`.

Не сделаны и не заявлены: измерение точности REM, гарантированное обнаружение каждого эпизода, собственная настройка haptic/alert-duration AlarmKit, подписанная IPA-сборка или публикация.
