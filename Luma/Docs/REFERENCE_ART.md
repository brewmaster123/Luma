# Reference Night: art resources

Источник: `codex-clipboard-838955cc-7c73-4cf1-84ad-7b414d1e12df.png`, 1024 × 1536. Профиль источника не объявлен; в FigCraft интерпретирован как sRGB. Прежние версии приложения не изменялись.

## Статические слои

| Native asset | Размер | Происхождение |
|---|---:|---|
| ReferenceNightBackdrop | 1024 × 1536 | Встроенный ImageGen: очищенная подложка исходного эталона без UI, луны, цепочки и запечённой падающей звезды. Облачная композиция сохранена по референсу, отсутствующие участки реконструированы. |
| ReferenceMoon | 1024 × 520, RGBA | FigCraft: пиксели исходной луны и цепочки вырезаны векторной маской. Сам месяц не генерировался и не перекрашивался. |
| ReferenceCloudFar | 1024 × 520, RGBA | Исходные пиксели левого облачного массива с радиальной альфа-маской; максимум x=362, вдали от раскрытой части месяца. Содержит несколько исходных левых звёзд. |
| ReferenceCloudNear | 1024 × 520, RGBA | Правый передний облачный массив очищенной подложки, мягкая альфа-маска. Использован чистый слой, чтобы не возвращать запечённые звёзды в раскрытую область. |
| ReferenceCloudBottom | 1024 × 1536, RGBA | Исходные нижние облака в y=1256…1392, с вертикальным альфа-переходом. UI в изображение не входит. |

Все слои размещаются в исходной системе координат с началом (0, 0). Для первых двух облачных слоёв и луны их видимый кадр занимает (0, 0, 1024, 520) общей композиции; остальная часть прозрачна. Точка подвеса — (554, 0). Подробности — `art-geometry.json`.

Для самостоятельного просмотра подготовлены полные PNG и компактные изображения шириной 640 px. `reference-clean-backdrop-compact.jpg` весит 57 KB и удобен для inline-просмотра; нативная версия использует полный PNG. Прочие компактные изображения — lossless WebP с прозрачностью.

## Цветовые измерения

`reference-measurements.json` содержит реальные сэмплы RGB/HEX, ROI, фильтры, медианы и профиль кнопки. Это результирующие пиксели плоского изображения. Исходные альфа-значения и отдельные исходные paint-слои математически не восстанавливаются однозначно из PNG; такие данные не выдаются за извлечённые.

Надёжные медианы ядра надписей: заголовок `#F9EBC8`, надпись кнопки `#F8EBCA`, цифры 30 `#FBE7CD` / `#FBE3C6` / `#FAE4C8` по вертикальным полосам, вспомогательный текст `#B4B1C2`, неактивная книга `#7E7D98`. Фон: `#020A17` / `#020B19` сверху и `#050E1E` в середине. Профиль кнопки в x=340: от `#2C3250` в y=824 до `#0F182C` в y=895.

## Проверка

Луна сверена с исходником: 34 886 непрозрачных пикселей луны/цепочки, 0 различий RGB, максимальная разница канала 0. Полностью прозрачных пикселей в её кадре — 496 453. Отчёт: `art-verification.json`. Альфа-край маски и изменяемая во времени интенсивность — отдельные операции отображения; утверждение о точном совпадении относится к пикселям тела луны, а не ко всей сцене.

Фон очищен генерацией и не считается попиксельно тождественным исходному эталону. Запечённая падающая звезда и точки в раскрытой области намеренно отсутствуют, поскольку ограничение геометрической зоны исключения важнее их статического положения на референсе. Текст, числа, кнопки, карточки, навигация и переключатели в художественные слои не запекались.

Редактируемая сборка FigCraft: `Reference-Art-Layers.figcraft`. Режим генерации: встроенный ImageGen, только очистка подложки; точный промпт сохранён в `PROMPTS.md`.
