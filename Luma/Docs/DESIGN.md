# Дизайн Luma

Исследование выполнено 7 сентября 2026 года. Изучены рекомендации Apple и публичные материалы Oura, Sleep Cycle и Headspace. Это обоснованный первый вариант дизайна; универсально «идеальный интерфейс для всех людей» нельзя установить без испытаний с пользователями.

## Источники и принятые решения

| Источник | Что применено в Luma |
|---|---|
| [Apple: Designing for watchOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-watchos) | Короткий сценарий на часах: состояние, время, включение/отмена и проба. Подробные настройки вынесены на iPhone. |
| [Apple: Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | Системные шрифты, Dynamic Type, подписи VoiceOver, состояния обозначены словами, крупные кнопки. Декоративная луна исключена из дерева доступности. |
| [Oura: How to use the Oura App](https://support.ouraring.com/hc/articles/360058599753-How-to-Use-the-Oura-App) | Небольшое число постоянных разделов и понятная иерархия. В Luma — «Ночь», «Дневник», «Настройки». |
| [Sleep Cycle: Liquid Glass](https://sleepcycle.com/sleep-talk/liquid-glass) | Спокойное оформление ночного сценария, читаемые настройки, основное действие без визуального соревнования с второстепенными блоками. |
| [Headspace: Sleep](https://www.headspace.com/sleep) | Мягкий тон текста и минимум оценочных метрик перед сном. Иллюстрации Luma созданы отдельно, материалы Headspace не копировались. |
| [Apple: App icon configuration](https://developer.apple.com/documentation/xcode/configuring-your-app-icon) | Оригинальная непрозрачная иконка 1024×1024 для обоих asset catalog; масштабирование выполняет Xcode. |

Это применение общих принципов, а не копирование чужого экрана или результат сравнительного исследования удержания пользователей.

## Визуальный язык

| Роль | Цвет |
|---|---|
| Фон | `#0C1120` |
| Карточка | `#171E30` |
| Вложенная поверхность | `#111728` |
| Главный акцент | `#C6B6F4` |
| Основной текст | `#F2EFF8` |
| Вторичный текст | `#B2B8C9` |
| Подтверждённое состояние | `#AAD8C5` |
| Ограничение / ожидание | `#ECD19B` |

Крупные заголовки используют системный serif, время — rounded с моноширинными цифрами, остальной интерфейс — системный шрифт. Радиус карточек 24 pt, числовых кнопок 15 pt. Основные числовые элементы имеют высоту не менее 50 pt. Важные действия имеют подписи; статус не передаётся одним цветом.

На главном экране постоянно доступна кнопка подготовки сессии в нижней области. Содержимое прокручивается; при крупном размере текста графика и описания не должны вытеснять действие за пределы экрана. Реальную работу Dynamic Type и VoiceOver нужно проверить в Xcode и на устройствах.

Декоративная луна статична. В нативном интерфейсе нет непрерывно мигающих или пульсирующих объектов перед сном. В HTML-макете анимация запускается только кнопкой пробы и завершается сама.

## Текст и состояния

- «Ожидаем подтверждение часов» до ответа watchOS.
- «Сигналы запланированы» после успешного добавления конечной серии.
- «Недостаточно данных» вместо вымышленного процента уверенности.
- «График появится после сна» вместо демонстрационной медицинской истории.
- «Рисунок вибрации задают часы» рядом с выбором количества.
- «Каждый сигнал заканчивается сам» без переключателя ручного отключения.

## Как проверить удобство

Дать человеку без объяснений три задания: подготовить серию из трёх сигналов на новое время, найти пробу и записать сон. Наблюдать, на каком шаге возникает вопрос. Отдельно проверить различимость кнопок в тёмной комнате на низкой яркости, максимальный размер текста и понимание состояния «Ожидаем подтверждение часов».

`Interface-preview.html` показывает взаимодействия концепции. `Luma-design.png` — отрисованная иллюстрация. Они не доказывают компиляцию SwiftUI или точное совпадение с каждой моделью iPhone.
