# Luma 0.2 — дизайн

Сохраняем три понятных раздела: «Ночь», «Дневник», «Настройки». Основное действие на первом экране — начать непрерывный сеанс. Обычные будильники находятся ниже отдельным списком. Источник данных и устройство, подающее сигнал, — независимые настройки.

## Типографика

Manrope: Regular 400 для текста, Medium 500 для заголовков и времени, SemiBold 600 для акцентов. Выбор основан на мягкой геометрии, открытых формах и полноценной кириллице, подходящей коротким спокойным интерфейсам. Это дизайнерское решение, а не доказательство существования универсально лучшего шрифта для сна. Сравнивались системная типографика Apple и доступные кириллические гарнитуры; выразительные засечковые заголовки прежнего макета убраны.

Официальные источники: [Google Fonts](https://fonts.google.com/specimen/Manrope), [авторский репозиторий](https://github.com/sharanda/manrope). В Resources лежат статические экземпляры 400/500/600 и SIL OFL. Их PostScript-имена согласованы с `.custom`, файлы включены в ресурсы обеих целей. SwiftUI масштабирует текст относительно Dynamic Type; длинный контент прокручивается.

## Свет и движение

Фон #0B0F1C; поверхности #171C2F / #101525; основной текст #F0EDF8; лавандовый #CCBDF7; вторичный #A6ABC2; спокойный мятный #A8D7CB. Тонкая граница и небольшой перепад света придают карточкам глубину. Нет фонового видео, 3D-сцен, тяжёлых bitmap-анимаций, удалённых шрифтов или рекламных модулей.

Луна состоит из нескольких векторных элементов. Амплитуда движения — несколько точек, цикл 7 секунд, орбита едва поворачивается. Движение останавливается при Reduce Motion, энергосбережении и неактивном iOS-приложении. В HTML учитываются prefers-reduced-motion и видимость страницы. Нажатие чуть уменьшает кнопку при разрешённой анимации.

## Честные состояния

- Без часов — компактное пояснение о меньшей надёжности и отсутствии измеренного процента.
- Необходимые разрешения запрашиваются для выбранной возможности.
- Нет данных — нет выдуманного графика REM. Утренний график строится из реальных записей Apple, когда они есть.
- Отклик опционален; после завершения нет обязательного опроса.
- «Толкование снов · Скоро» показывает анонс, без неработающего AI-чата.
- Количество Watch-уведомлений и подтверждение их принятия не называются числом ощущённых постукиваний.

## Макет

`Interface-preview.html` автономен: Manrope встроен как WOFF, графика SVG, сценарии на локальном JavaScript. На широком экране показаны iPhone и Watch, на узком — приложение. Два исходных будильника — демонстрационные. Сеансы и эпизоды можно добавить вручную; макет не притворяется датчиком сна. Текст снов экранируется, изменения сохраняются в localStorage, голос хранится в памяти текущей вкладки. Голосовая проба зависит от поддержки микрофона браузером. Нативный код отдельно сохраняет записи на iPhone.
