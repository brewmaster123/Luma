# Устройство: 0.9.6 (22)

Все физические сценарии ниже пока НЕ ВЫПОЛНЕНЫ. Запускать приложение с Home Screen без Xcode debugger: debugger мешает suspension. Записать модель/OS builds, громкость, Silent/Focus, заряд, Watch/наушники и точный build приложения.

Сначала разрешить Luma на Watch, включить ночной фон на iPhone, дождаться Watch ack. Снимать звук и вибрацию внешней записью от 15 секунд до срабатывания до 60 секунд после предполагаемого Stop.

| Сценарий | Критерий |
|---|---|
| Фон 5 минут без будильника | Очень тихий звук, Watch не вибрируют |
| Проба через 60 секунд, locked iPhone | AlarmKit слышен ≤4 сек, остановка без прикосновения, нет повтора |
| Та же проба, unlocked iPhone | Тот же Stop и отдельный сигнал Watch |
| Locked + приложение в фоне 30+ минут | Stop не требует возобновления UI |
| Три непрямых события по 30 минут | Каждый Stop, следующие даты/ID сохранены |
| Watch app открыто/закрыто | Один local cue; отсутствие двойного foreground haptic |
| Нет связи после подтверждения расписания | Предварительно принятые Watch cues остаются на Watch |
| Отмена/редактирование | Новый full plan удаляет старые ID; поздняя старая ревизия не возвращает их |
| AlarmKit прерывает аудио | Stop-window завершается; дождь возобновляется или очередь снимается с явным статусом |
| Телефонный звонок/другой плеер/снятие наушников | Нет ложного статуса готовности; при потере audio runtime очередь снята |
| Silent и Focus по отдельности | Измерить реальный результат; локальный Watch cue может подавляться Focus |
| Остановка фона/системная Pause | Сначала снята очередь, затем прекращён дождь |
| Холодный запуск/перезагрузка/unlock | Старые unsafe IDs сняты, исходные настройки/дневник/каденс сохранены |
| Force quit | Отдельно зарегистрировать ограничение: Stop не гарантирован, системная очередь может остаться |

Проверить дополнительное системное отражение AlarmKit на Watch: нет ли двойного сигнала или продолжающейся вибрации после iPhone Stop. Локальная очередь и AlarmKit forwarding — разные механизмы.

Сохранить diagnostic JSONL и Watch count/revision ack. Принятый ID или успешный Stop не равен акустическому измерению. При продолжающемся звонке нажать системную Stop и отметить FAIL, а не засчитывать ручное действие как успех.
