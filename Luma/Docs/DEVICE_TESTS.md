# Устройство: 0.9.7 (23)

0.9.6 (22) — эталон, подтверждённый пользователем. Новые варианты 3–10 секунд в 0.9.7 пока физически не проверены. Запускать без debugger, записать модель/версии iOS/watchOS, build, громкость, Focus/Silent. Измерять звук внешней записью; сообщение Stop в журнале само по себе не измерение.

| Сценарий | Ожидаемый результат |
|---|---|
| Первый запуск после 0.9.6 | Длительность 4 с, прежние данные и настройки сохранены |
| Изменить на 3, затем закрыть и открыть | Значение 3 сохранено; для возобновления ночного режима включить фон |
| Проба через 60 с: 3/4/10, locked и unlocked | Звук прекращается в выбранный срок без прикосновения и больше не возобновляется |
| Умный будильник: 3 и 10 с | Тот же срок, следующая дата/UUID не сдвинуты |
| Непрямой метод: три события по 30 минут, 3 и 10 с | Каждый Stop выполняется, серия продолжает свой исходный отсчёт |
| Во время 10-секундного сигнала выбрать 3 | Текущий сохраняет 10, следующие используют 3 |
| Изменить будущий срок 3→10 и 10→3 | Старый Task не даёт раннего/позднего Stop, системный будильник не дублируется |
| Locked + фон 30 минут, срок 10 | Дождь/прерывание не обрывает сигнал на прежних 8 секундах |
| Watch app открыто/закрыто, оба состояния iPhone | Прежний локальный сигнал Watch, подтверждённое расписание и отсутствие лишней вибрации от фона |
| Потеря audio runtime/системная Pause | Будущая очередь снимается с явным статусом; нет ложной готовности |
| Возврат к 0.9.6 после снятия очереди | Данные читаются, применяется прежний срок 4 с |

При испытании снять 15 секунд до события и 60 секунд после предполагаемого Stop. Отдельно проверить периоды слабой связи, interruption звонком, Focus/Silent и возможное системное отражение AlarmKit на Watch. Force quit сохраняет прежнее ограничение runtime. При непрекращающемся звонке использовать системную Stop и записать FAIL.
