# Физическая проверка 0.9.5 (21)

Все сценарии ниже **НЕ ВЫПОЛНЕНЫ**. Windows/static/grammar не проверяют AlarmKit на устройстве. WAV EOF остаётся гипотезой.

Установить 0.9.5 (21), записать модель, точный build iOS 26+, watchOS, наличие Watch/наушников/Bluetooth, громкость, Silent/Focus, заряд и состояние процесса. Для обновления сохранить данные установкой поверх, не удаляя Luma. После reboot сначала unlock.

Снимать внешним устройством непрерывный звук и экран/часы времени: начать до срабатывания, продолжать минимум 60 секунд после ожидаемого EOF. Измерить длительность слышимой части и проверить повторы. Затем дождаться следующего события. Запуск в foreground с резервной Stop не доказывает EOF в suspended состоянии.

| Сценарий | Проверяемый результат | Статус |
|---|---|---|
| Проба через 60 секунд без Watch, приложение открыто | Слышен выбранный WAV ≤4 сек; Stop/Cancel журнал отдельно от акустики | Не выполнен |
| Умный будильник, iPhone locked/background | Слышен звук, затихает самостоятельно; нет повтора 60 сек | Не выполнен |
| Умный будильник после длительного background/suspension | Окончание не зависит от открытого интерфейса/таймера процесса | Не выполнен |
| Непрямой метод, три события по 30 минут | Каждое заканчивается; следующие начала сохраняют 30 минут | Не выполнен |
| Предыдущий сигнал закончен, следующий UUID | Нет блокировки следующим активным состоянием, нет накопления звонков | Не выполнен |
| Умный будильник и непрямой метод одновременно | Stop одного UUID сохраняет второй и будущую серию | Не выполнен |
| Locked iPhone + подключённые Watch | Есть слышимый звук; одной карточки на часах недостаточно; записать оба маршрута | Не выполнен |
| Та же пара с Silent и отдельно Focus «Сон» | Измерить фактическую доставку/длительность/маршрут, не предполагать результат | Не выполнен |
| Force quit после постановки | Записать доставку, EOF/повторы и системное состояние без процесса Luma | Не выполнен |
| Relaunch до и после события | Нет дубликатов, существующие ID не отменяются как legacy | Не выполнен |
| Reboot, unlock, повторный запуск | Корректное восстановление доступа/очереди; не считать старые записи подтверждёнными без проверки | Не выполнен |
| Короткий голос, длинная мелодия и базовый WAV | Все конечные копии ≤4 сек с fade, оригиналы/дневник целы | Не выполнен |
| Обновление с schema 1 и отдельно schema 2 | Старая очередь удалена до новой, прошлое не воспроизводится, начало сеанса сохранено | Не выполнен |
| Отмена при подготовке/отзыв разрешения | Нет возвращения отменённых ID; ошибка не маскируется успехом | Не выполнен |

В settings: «Проба AlarmKit» / проба через 60 секунд; сначала выполнить под наблюдением. При продолжающемся звонке нажать системную «Остановить», записать время ручного нажатия и отметить FAIL автоматического окончания.

Различать: файл закончился; звук затих; UUID ушёл; системная карточка закрылась. PASS требует измеренного звука без ручного действия и сохранения следующего события. При прерывании звонком/другим аудио сценарий повторить, не засчитывать прерывание как самозавершение.

Сохранить OSLog и alarmkit-wave-events.jsonl из приложения. Логи содержат только попытку/подтверждение постановки, наблюдение alerting и результат Stop. Они не подтверждают акустический старт/EOF. Не публиковать исходные голосовые записи/дневник.

До выполнения locked/suspended, серии и Watch сценариев verified-флаги остаются false. Если WAV повторяется, гипотеза не прошла: выпуск не объявлять исправлением фонового автозавершения.
