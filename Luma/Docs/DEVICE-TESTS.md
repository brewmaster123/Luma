# Luma 0.4.1 — сначала проверить исправления Watch

| Сценарий | Ожидаемый результат |
|---|---|
| Установка поверх прежней копии, обе цели с одной Team | Внизу Watch видно Luma 0.4.1 (5), связь с iPhone работает; дневник сохранён. |
| Нажатие на пустой край кнопок | Вся карточка реагирует, появляется состояние нажатия. |
| Разрешение ещё не запрашивалось | Системная форма на Watch, индикатор ожидания и результат после ответа. |
| Уведомления уже разрешены или запрещены | Явный статус/подсказка, отсутствие новой системной формы не выглядит бездействием. |
| HealthKit ранее разрешён/запрещён | «Запрос обработан», путь к настройкам; Luma не заявляет, что знает read authorization. |
| Быстрые повторные нажатия уведомлений/Health | Не запускаются две формы; старое чтение статуса не перезаписывает результат нового запроса. |
| Ошибка включения фонового HealthKit | Кнопка Health не остаётся ожидающей; ошибка видна отдельно. |
| Проба 1/2/3/5 сигналов | Номер текущего сигнала, конечное завершение; второй тап останавливает. Число физических импульсов системного рисунка не обещается. |
| Выход из Luma во время пробы | Проба отменяется; после возврата кнопка снова доступна. |
| Пауза/возобновление при активной ночи iPhone | Watch приостанавливает и возвращает наблюдение; другая ночь не возобновляется старой кнопкой. |
| Ночи на iPhone нет | Кнопка остановки не предлагается; показано, где начать сеанс. |

Эти испытания новой версии на устройствах ещё не выполнены. Если кнопка всё ещё не реагирует, снимите экран вместе со строкой версии и сохраните лог Xcode для Luma Watch.

## Проверки унаследованного AlarmKit

Эти проверки ещё не выполнены. Нужен iPhone с iOS 26+. Сначала дневные пробы; обязательная автоостановка в фоне не реализована полностью.

| Сценарий | Что проверить |
|---|---|
| Установка поверх прежней версии | История и звуки остаются, старые уведомления не дублируются. |
| Мелодии 4/8/15 секунд при открытой Luma | Реальные начало/конец звука, выполненный stop, отсутствие повторения. |
| Голос 3/28 секунд, импорт WAV/M4A/MP3 | Выбранная дорожка, обрезание при задержке системного начала. |
| Silent + Focus «Сон» + блокировка | Слышимость и остановку проверять отдельно. |
| REM с настоящим акустическим наблюдением | Микрофон возвращается после stop; собственный звук исключён из оценки. |
| Watch без микрофона | Свежесть пульса, фоновые callback и пропуски. |
| Luma приостановлена до звонка | Записать задержку/отсутствие stop; система может звонить без кода Luma. |
| Luma принудительно закрыта | Остановить вручную, затем проверить восстановление при запуске. |
| Близкие будильники/проба во время звонка | Раздельные сроки, без сброса срока и запуска микрофона поверх второго сигнала. |
| Завершение REM во время schedule/звука | Сигнал отменён после запоздалого schedule; повтор отмены после ошибки. |
| Отказ/отзыв разрешения AlarmKit | Понятная ошибка, обычное уведомление не подменяет сигнал. |
| Phone / Phone + Watch / Watch-only | Системное отражение без дубля; Watch-only 1/2/3/5 уведомлений, 3/8/12 секунд. |
| Недельный будильник, полночь, часовой пояс | Порядок следующего срабатывания; повтор после stop сохранён. |
| Просроченный одноразовый, редактирование/удаление | Не возникает завтра, старое время отменено, пустой край времени нажимается. |
| Голос дневника/отклика, отмена черновика | Воспроизведение после перезапуска, новые вложения удалены без потери старых. |

При позднем возвращении истёкший сигнал должен получить stop сразу. Успешная команда stop не заменяет измерение реального конца звука.

Для подтверждения REM требуется отдельное сравнение с эталонной регистрацией сна. Проценты авторской справки не подтверждены тестами Luma.
