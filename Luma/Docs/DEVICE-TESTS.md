# Luma 0.3 — проверка на ваших устройствах

Эти проверки ещё не выполнены. Сначала проведите короткие дневные пробы на iPhone и Watch; после успешных проб переходите к ночному сеансу.

| Проверка | Ожидаемое поведение |
|---|---|
| Silent включён, громкость ненулевая, проба Luma | Мелодия/голос/импорт слышны, дорожка затихает сама. Переключатель вибрации влияет только на собственный iPhone-сигнал. |
| iOS 26, системный будильник через 2–3 минуты, экран заблокирован | После разрешения AlarmKit звучит через Silent и фокусирование «Сон». Системный звонок может требовать остановки. |
| Повтор предыдущей пробы с закрытой Luma | Заранее установленный системный будильник продолжает принадлежать системе. REM-анализ закрытого приложения не работает. |
| Разрешение AlarmKit отклонено | Будильник не объявляется успешно поставленным; доступна понятная ошибка/повторный запрос. |
| Изменение времени, выключение и удаление | Старое системное время отменяется; нет двойного звонка. Прошедший одноразовый не возникает на следующий день. |
| iPhone + Watch с системным будильником | Проверить системное отражение на часах, отсутствие дополнительной серии Luma. Рисунок/маршрут задаёт система. |
| Короткий режим + ночной микрофон + блокировка | При работающем анализе собственная короткая дорожка звучит сквозь Silent. Проверить прерывания звонком, Siri и сменой аудиомаршрута. |
| Watch-источник без микрофона, погашены оба экрана | Замерить реальную свежесть пульса и поступление событий. При недостатке данных сигнал пропускается; непрерывность не гарантирована. |
| Импорт MP3/M4A/WAV из локальных файлов и iCloud Drive | Первые 28 секунд копируются, исходник не меняется; DRM/ошибка/слишком большой файл дают сообщение. |
| Голос дневника, 1–2 секунды и длинная запись | После остановки и сохранения прослушивается после перезапуска; голос без текста допустим. |
| Отмена редактора с новой голосовой дорожкой | Новая дорожка удаляется, ранее сохранённые заметки остаются. Удаление отдельной дорожки действует после «Сохранить». |
| Голосовой отклик завершённой сессии | Необязателен; сохраняется локально, не влияет на оценку как текстовая/звуковая метка REM. |
| Будильники 09:00, 12:00, 07:00 до 07:00 | Список 07:00 → 09:00 → 12:00. После полуночи и с разными днями важна фактическая следующая дата. |
| Пустая «Ночь», затем несколько будильников | Без лишней прокрутки на обычном размере текста; с будильниками список прокручивается. Касание пустого края времени открывает редактор. |
| Интервалы Watch 3/8/12 | Проверить принятие конечной серии уведомлений и физическое поведение watchOS. |

Сравнение отметок подсказок с утренним графиком Apple — предварительное сравнение алгоритмов. Оно не измеряет независимую точность REM. Для утверждений о проценте попаданий требуется эталонное исследование сна.
