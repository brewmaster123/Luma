# Проверка Luma 0.2 на устройствах

Эти испытания ещё не выполнены. Заполняйте фактические результаты, а не предполагаемый успех. Для первой установки нужен подписанный билд. Начните с короткой дневной проверки, затем проверяйте работу ночью.

## Сборка и подготовка

- [ ] Новый workflow завершил `swift test`, Watch build и iPhone build.
- [ ] IPA содержит исполняемые файлы обеих частей, три Manrope и WAV-мелодии. Установлена подписанная сборка 0.2 (2).
- [ ] Luma открывается на обоих устройствах. HealthKit и уведомления разрешены там, где используются; микрофон запрашивается только для записи/наблюдения.
- [ ] Старое приложение обновлено с тем же bundle ID: прежние записи снов сохранены, данные не очищены при ошибке чтения.

## Три маршрута и автоокончание

Для каждого маршрута отдельно: iPhone + Watch / iPhone / Watch.

- [ ] Проба в открытых приложениях: телефон действительно воспроизводит выбранный звук, Watch даёт конечную пробу 1/2/3/5.
- [ ] Звук сам прекращается после 4/8/15 секунд. Голос 1–28 секунд заканчивается ровно на конце, без повторов. Запись сама заканчивается на 28 секунде.
- [ ] Будильник через 2 минуты: проверить открытый/заблокированный телефон, открытые/спящие часы, на руке/снятые часы, Focus «Сон», Silent Mode и подключённые наушники.
- [ ] Отметить, **какое устройство физически звучало/вибрировало**, длительность, задержку и количество коротких уведомлений. Не считать UI «запланировано» фактом доставки.
- [ ] В Watch-only нет звука при бесшумном режиме. При выключенном Silent Mode ожидается системный звук обычного уведомления; это текущая граница реализации.
- [ ] В Phone-only при заблокированном iPhone проверить возможный перенос уведомления на Watch. Это блокирующая проверка перед обещанием строгой маршрутизации.
- [ ] В Both проверить совместное срабатывание; синхронность не считается доказанной до этих испытаний.

## Будильники

- [ ] Создать 60+ будильников, закрыть и открыть приложение: весь список сохранён, удаление/редактирование/тумблеры независимы.
- [ ] Ближайшая системная очередь учитывает бюджет 48 запросов; Watch-серия из 5 занимает 5 запросов. Непопавшие события и отказ разрешений отображаются.
- [ ] Открытие обеих частей пополняет очередь. После отключения или удаления будильника его будущих сигналов нет.
- [ ] Одноразовый будильник после срабатывания не повторяется завтра. Повтор по дням корректен около полуночи, смены часового пояса и перехода DST после открытия приложения.
- [ ] Голосовая дорожка остаётся доступна после перезапуска/блокировки. Удаление дорожки, занятой будильником или сеансом, запрещено с пояснением.

## Микрофон и сеанс

- [ ] iPhone-only запускается без парных Watch и без разрешения Health. Предупреждение не содержит выдуманного процента.
- [ ] Через несколько минут появляются пригодные диагностические признаки; тишина/недостаток данных не подменяются REM.
- [ ] При блокировке экрана настоящий микрофонный анализ продолжает работать настолько долго, насколько разрешает iOS; зафиксировать прерывания и энергопотребление.
- [ ] Телефонный звонок, смена аудиомаршрута, отключение микрофона или сбой engine переводят сеанс на паузу; требуется явное возобновление. После принудительного завершения нет обещания работающего анализа.
- [ ] Собственный сигнал и ближайшие загрязнённые окна не вызывают новое REM-срабатывание.
- [ ] Завершение останавливает микрофон и снимает будущие REM-уведомления. Отдельные будильники продолжают работать по своему расписанию.

## Watch и непрерывные эпизоды

- [ ] Записать частоту/задержку реального пульса и дыхания, доступность Motion при погашенном экране, моменты получения WatchConnectivity-пакетов. Не считать старую отметку свежей.
- [ ] При недоступной связи REM-сигнал помечен как пропущенный, после восстановления связи он не проигрывается задним числом.
- [ ] Один длительный предполагаемый эпизод не вызывает повторов. Новый подтверждённый правилами эпизод после устойчивого выхода может дать следующую подсказку; общего лимита за сеанс нет.
- [ ] Отсутствие данных не признаётся выходом из REM. Перезапуск не повторяет сохранённую подсказку.
- [ ] Остановка REM на Watch блокирует последующие команды этого сеанса, включая повтор конфигурации. Новый сеанс можно подключить заново.

## Дневник и доступность

- [ ] Можно завершить сеанс и ничего не заполнять. Можно позднее записать, изменить или удалить отклик.
- [ ] При нескольких подсказках можно выбрать конкретную или «не помню». Общий неоднозначный отклик исключён из настройки.
- [ ] Настройка выключена по умолчанию; одна ночь не меняет алгоритм. Отключение обнуляет поправку, удаление отклика удаляет его влияние.
- [ ] Обычные записи снов работают. «Толкование снов · Скоро» не вызывает AI и ничего не отправляет.
- [ ] Кириллица отображается Manrope без подмены на засечки; крупный Dynamic Type и VoiceOver не скрывают основные кнопки.
- [ ] Reduce Motion, энергосбережение, уход в фон останавливают анимацию луны. На самом слабом поддерживаемом тестовом устройстве нет заметного торможения.

## Исследование точности — отдельно

Успех сборки и доставки не означает попадания в REM. Для первого сравнения экспортируйте время предполагаемых эпизодов и утреннюю историю Apple; это сравнение алгоритмов. Независимая точность требует эталонной регистрации сна, разметки, определения метрик, нескольких ночей и проверки на людях, чьи ночи не использовались для настройки. Отдельно измеряйте REM precision/recall, задержку сигнала, пропуски из-за данных/связи и пробуждения. До этого не обещайте конкретный процент точности или каждую фазу.
