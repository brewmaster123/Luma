# Изменения 0.4.2 (6)

База: Luma-iPhone-AppleWatch-v0.4.1-Watch-fix.zip (51511193f761a7d2800fd4b669f9a69c53fb4ab15a81645cf7509b0c966d54f3).

- Сигналы iPhone переведены с AlarmKit на ordinary local notifications. Конечные звуки без loop и фонового stop-таймера.
- Совместимая отмена старых AlarmKit alarms перед созданием новых. Файлы и записи пользователя сохранены; стабильный com.sevchlenko.luma.
- Памятка Silent off / Focus «Сон» / разрешить Luma, публичная кнопка настроек уведомлений, сохранение черновика при отмене и возврате.
- Для обоих маршрутов с Watch снова доступна своя конечная серия часов и её 3/8/12 секунд. Системное зеркалирование не управляется программно.
- Перестройка очереди сохраняет немедленно ожидающий запрос; собственный звук исключён из акустической оценки.
- Исправления Watch 0.4.1 сохранены, код повторно просмотрен. UI кнопок, FiniteHaptics, HealthService, WatchBridge и LumaWatchApp не переписаны.
- Номер версии виден на телефоне и часах: 0.4.2 (6).

Полный протокол и пределы проверки: VALIDATION.md. Нативная сборка и испытания этой версии ещё не проведены здесь.
