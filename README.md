# Luma 0.9.9 (25) — эталонный экран «Ночь»

Экспериментальная копия Design Experiments/V.0.9.9-Reference-Night создана из предыдущего изолированного эксперимента 0.9.8 (24), который основан на рабочей V.0.9.7 (23). Папки всех прежних версий, включая V.0.9.6 и Baselines, не изменяются.

Новый экран использует приложенный эталон 1024 × 1536: извлечённый полумесяц с цепью, отдельные облачные слои, измеренные цвета, серифную типографику, нативные кнопки +/- и «Начать сеанс», список независимых будильников и нижнюю панель только из трёх значков. Названия вкладок доступны VoiceOver, но визуально отсутствуют. Приветственная IntroductionView больше не показывается; прежняя отметка завершения знакомства сохраняется штатным методом при открытии корня.

Справка непрямого метода открывается перед запуском, если пользователь не выбрал «Больше не показывать». Отмена не запускает сигналы. Штатная проверка readiness после справки сохраняется. Справка умного будильника открывается нажатием на иконку/заголовок/подпись; отдельный плюс сохраняет добавление нового будильника. Редактирование, удаление и переключение используют прежние AppModel/AlarmEditor.

Декорация: ±1,5° за 11,2 секунды вокруг точки подвеса (554, 0), 2,5% плавное изменение интенсивности за 12 секунд, практически незаметный дрейф отдельных облачных слоёв и по одной редкой падающей звезде с интервалами 40–90 секунд. Пустая область полумесяца описана криволинейной зоной с запасом; точки и полная траектория обратным поворотом переводятся в систему текущей луны перед проверкой. Reduce Motion, фон и уход с экрана останавливают декоративную временную шкалу.

## Проверка

GitHub Actions ветки design/0.9.9-reference-night собирает iPhone и Watch, выполняет прежние core/audio/queue проверки, собирает симулятор и записывает фактический PNG приложения. Shared scheme LumaReferenceUITests выполняет тесты изменённых взаимодействий. До получения успешного CI эта копия не объявляется проверенной на Xcode или готовой к установке.

Для воспроизводимого снимка используется -reference-screenshot: один тестовый будильник 07:00 по будням, анимация зафиксирована в нуле, сервисы не запускаются и пользовательское хранилище не читается. Касания отключены только в этом режиме. Аргумент -reference-ui-test останавливает лишь декорацию: тесты взаимодействий используют обычный интерфейс и бизнес-логику, без выдачи разрешения на запуск сигналов.

Команды на Mac:

    cd Luma
    bash scripts/check-on-mac.sh
    xcodebuild -project Luma.xcodeproj -scheme LumaReferenceUITests -destination 'platform=iOS Simulator,name=iPhone 17 Pro' CODE_SIGNING_ALLOWED=NO test

## Известные визуальные пределы

Times New Roman — ближайший по измеренным метрикам системный шрифт, но исходный шрифт эталона не идентифицирован. SF Symbols и минимальные области касания могут отличаться от художественных пикселей. На высоких современных iPhone художественный холст равномерно масштабируется с боковой обрезкой, интерфейс адаптируется по ширине и высоте. Облака чистой подложки подготовлены отдельно; их точность должна оцениваться по снимку симулятора. Из исходного неба удалён метеор в запрещённой области раскрытого полумесяца.

Bundle ID com.sevchlenko.luma, подпись, аудиотракт, AlarmKit/Watch, планы и форматы хранилища сохранены. Новый флаг справки — отдельная настройка UserDefaults, старые версии её игнорируют. Рабочие версии не перезаписывались; приложение на телефон автоматически не устанавливается.
